# 项目介绍

[Tnnevol 技能库](https://github.com/tnnevol/skills) 是 [智能技能](https://agentskills.io/home) 的实用合集，用于人工智能辅助开发，涵盖常用工具、接口集成和最佳实践。

## 项目定位

本项目用于**开发和发布智能技能与命令行工具**，文档同时作为**开发日志**，记录每个技能的开发进度、已完成功能、当前状态和未来计划。

## 技能列表

当前包含 7 个技能和 1 个命令行应用：

| 技能 | 描述 | 类型 |
|-------|------|------|
| [自动保存](/skills/autosave/) | 开源网盘自动保存服务 - 任务管理、配置、接口 | 接口集成 |
| [禅道](/skills/chandao/) | 禅道项目管理 - 任务、需求、缺陷、产品接口操作 | 接口集成 |
| [钉钉](/skills/ding/) | 钉钉群聊中快速联系其他代理 | 接口集成 |
| [飞牛文档](/skills/fnnas-docs/) | 飞牛应用开发文档 - 快速开始、开发指南、开放接口、命令行工具 | 文档 |
| [博客管理](/skills/halo/) | 博客内容管理 - 创建、查询、更新、发布文章 | 接口集成 |
| [笔记管理](/skills/memos/) | 自建笔记管理 - 笔记、标签、评论、分享和附件 | 接口集成 |
| [网盘聚合](/skills/openlist/) | 网盘聚合管理 - 文件、分享、后台和存储 | 工具 |

## 开发进度

### 已完成

- ✅ **自动保存** - 网盘自动保存全功能：任务管理、配置管理、分享详情、运行任务
- ✅ **禅道** - 禅道项目管理全功能：产品、项目、需求、任务、迭代、缺陷、测试用例
- ✅ **钉钉** - 钉钉代理通讯：联系人、查询代理
- ✅ **飞牛文档** - 飞牛应用开发完整文档：快速开始、核心概念、开放接口、命令行工具、案例
- ✅ **博客管理** - 博客内容管理：文章、分类、标签、单页管理
- ✅ **笔记管理** - 笔记管理全功能：笔记、标签、评论、分享、附件、表情回应
- ✅ **网盘聚合** - 网盘管理：环境配置、命令参考
- ✅ **网盘命令行工具** - 独立命令行应用发布
