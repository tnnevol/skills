# vitepress-mermaid-renderer

面向 VitePress 的 Mermaid 交互式图表文档技能。它将上游项目中文文档整理为可供智能体按主题检索的安装、配置、工具栏、类型、示例和故障排除参考资料。

## 安装

```bash
npx skills add tnnevol/skills --skill=vitepress-mermaid-renderer -g -y
```

## 使用

当用户询问以下内容时使用该技能：

- 在 VitePress 中安装或接入 `vitepress-mermaid-renderer`
- Mermaid 图表的缩放、拖拽、重置、复制、下载和全屏
- 明暗主题切换、静态 SVG、工具栏布局和 CSS token
- `securityLevel`、SVG 清理、hydration 和可访问性排错

完整参考资料维护在 [`skills/vitepress-mermaid-renderer`](https://github.com/tnnevol/skills/tree/main/skills/vitepress-mermaid-renderer)；来源为[上游项目文档](https://github.com/sametcn99/vitepress-mermaid-renderer/tree/main/docs)。
